# Лабораторная работа 2

## Задание

Вариант 14.

Написать функцию, которая преобразует цвет из HEX-формата в RGB-формат
(например, "#FF0000" -> "rgb(255, 0, 0)").

## Реализация

Функция возращает строку "rgb(r, g, b)". Если на вход передаётся не строка, или
строка не из 7 символов, или некорректного формата, то кидается ошибка ошибка с
характерным текстом.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
