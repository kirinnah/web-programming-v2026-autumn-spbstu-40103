# Лабораторная работа 1

## Задание

Вариант 14.

Создать горизонтальное навигационное меню выделяется другим цветом. Для
реализации можно использовать `<nav>`, `<ul>`, `<li>`, и `<a>`. Один из пунктов
меню должен быть активным (например, при помощи class="active").

## Реализация

Добавлено навигационное меню с `<nav>`, `<ul>`, `<li>` и `<a>`. С помощью css
навигационное меню становится горизонтальным, а один из элементов активным.

## Запуск

Откройте `index.html` в браузере.
