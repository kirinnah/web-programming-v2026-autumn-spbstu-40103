# Лабораторная работа 3

## Задание

Вариант 14.

Реализуйте функцию countOccurrences(arr), которая возвращает объект с
количеством вхождений каждого элемента.

## Реализация

Если на вход подаётся пустой массив, то возвращается пустая мапа. Иначе
возвращается мапа с количеством значений в элементах.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
